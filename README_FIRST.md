# ⚠️ READ THIS FIRST
## Before You Start

**If you're merging/pulling this code for the first time, start here:**

1. **Read `QUICK_SETUP.md`** - Complete setup guide (10-15 minutes)
2. **PostgreSQL is REQUIRED** - SQLite is not supported
3. **You need to create database** - Follow Step 2 in QUICK_SETUP.md
4. **You need `.env` file** - Copy from `.env.example` (Step 3)

---

## Quick Checklist

Before running the application, ensure:

- [ ] PostgreSQL installed and running
- [ ] Database `shipping_db` created
- [ ] User `shipping_user` created
- [ ] `.env` file created in `backend/` directory
- [ ] Backend dependencies installed (`pip install -r requirements.txt`)
- [ ] Migrations run (`python manage.py migrate`)
- [ ] Frontend dependencies installed (`npm install`)
